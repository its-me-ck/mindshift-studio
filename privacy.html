Privacy Policy

Last updated: October 20, 2026

This policy covers Mindshift Uploader, a private tool used by the owner of the Mindshift Studio YouTube channel to upload that channel's own videos.

Who uses it

Only the channel owner signs in to Mindshift Uploader. It is not offered to the public and does not collect information from viewers or anyone else.

What it accesses

When the owner signs in with Google, the tool asks for permission to upload videos and to manage captions and thumbnails on the owner's YouTube channel. It uses this access only to upload Mindshift Studio videos, set their titles, descriptions, thumbnails and captions, and confirm which channel is connected.

How data is stored

The sign-in token is stored only on the owner's own computer. No data is sent to any server other than Google's YouTube Data API. Nothing is sold, shared with third parties, or used for advertising.

Google API Services

Mindshift Uploader's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from the Google Account third-party access page, which also deletes the tool's ability to use the stored token.
